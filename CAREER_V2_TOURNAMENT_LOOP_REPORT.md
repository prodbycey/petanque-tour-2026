## RANKING
- départ #2500 ;
- points ranking gagnés selon le parcours ;
- interpolation configurable vers Top 1000 / 500 / 300 / 150 / 50 / 1 ;
- niveau LOCAL / RÉGIONAL / NATIONAL / INTERNATIONAL mis à jour.

## RECRUTEMENT
- roster séparé de l'équipe active ;
- seuils Top 1000 / 500 / 150 / 50 ;
- même après déblocage, acceptation probabiliste selon résultats, affinité, prestige, ranking et force de l'équipe actuelle.

## IA
- matchs non-joueur simulés dans chaque tableau ;
- forme, victoires/défaites et points ranking IA évoluent ;
- Top 30 dynamique dans la sauvegarde ;
- très rares changements d'équipe dans la population de test après plusieurs tournois.

## LIMITATION IMPORTANTE
Le Match Core V1 verrouillé est un Match Core Tête-à-tête.
Les tournois Doublette/Triplette gèrent bien équipe, tableau et carrière, mais le match jouable conserve temporairement le format Tête-à-tête du Match Core validé. Aucun gameplay n'a été modifié.
