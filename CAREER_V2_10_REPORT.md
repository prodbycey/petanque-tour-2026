# PÉTANQUE TOUR 2026 — V2.10

Ajout visuel uniquement — aucun changement du mode de jeu, des règles ou de la physique de lancer.

## Terrains
Chaque famille de terrain possède maintenant un rendu visuel distinct :
- Dur / roulant : stabilisé compact, grain fin, peu de pierres.
- Gravier neutre : gravier calcaire traditionnel.
- Cassant / rocheux : pierres plus grosses, gris/brun, aspect irrégulier.
- Mou / sableux : sable clair, fin et plus uniforme.
- Humide / lourd : terre minérale plus sombre avec traces humides légères.

## Décors
Le décor est choisi selon la ville/région fictive du tournoi et varie aussi par tournoi grâce à une graine déterministe :
- Côte / Port-Azur / Port-Lumière / Belle-Dune : ambiance méditerranéenne, mer, pins, promenade.
- Rivargent : lac, collines et végétation.
- Castelvieil / Montélia / Aubecastel : murs et architecture minérale ancienne.
- Rocheval / Montbrun : collines et végétation plus sèche.
- Valmont / Belrive / Valcros / Saint-Romain : parc arboré.
- Nova Arena / Arena Centrale / Grand Boulodrome : enceinte sportive moderne.

## Public
Le public évolue selon le prestige ET le tour du tournoi :
- local : public réduit ;
- régional : plus rempli ;
- national : tribunes visibles ;
- international : forte affluence ;
- quarts / demies / finale : affluence qui augmente progressivement.
