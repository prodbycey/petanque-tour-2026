# PÉTANQUE TOUR 2026 — CARRIÈRE V2.4

Corrections explicites du Match Core pour les formats carrière.

- Tête-à-tête : 3 boules par équipe.
- Doublette : 6 boules par équipe.
- Triplette : 6 boules par équipe.
- Début de chaque match/mène : piste vide, aucune boule décorative.
- Les anciennes boules de composition sont cachées ET désactivées physiquement.
- Le cochonnet est caché au départ.
- Le joueur doit cliquer PRENDRE LE COCHONNET.
- Une fois pris, le cochonnet se lance avec le même geste swipe qu'une boule.
- L'IA prend puis lance également le cochonnet physiquement.
- La carrière transmet le format du tournoi au Match Core.
- Le backup MATCH_CORE_V1_VALIDATED_BACKUP reste inchangé.
